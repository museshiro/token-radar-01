Token launch radar: ranks the pre-token protocols in DefiLlama's index by implied launch value, with a concrete farm plan for each one. The model scores every protocol from the snapshot's own figures — TVL, seven-day growth, how long it has run with no token, and how many chains carry its TVL — and the static dashboard lets you sort, filter by category or chain, open a detail view with the model's full arithmetic, and re-rank the board live in a model sandbox.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
